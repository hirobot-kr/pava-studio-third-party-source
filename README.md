# PAVA Studio 오픈 소스 대응 소스

PAVA Studio와 PAVA USB Manager에 포함된 오픈 소스 구성요소의 대응 소스입니다.
HIROBOT Co., Ltd.가 게시합니다.

버전마다 `PAVA-Open-Source.zip`을
[Releases](https://github.com/hirobot-kr/pava-studio-third-party-source/releases)의
`v<버전>` 태그 릴리스에 첨부합니다. 버전은 PAVA Studio의 **도움말 → PAVA Studio 정보**에서
확인할 수 있습니다. 압축 파일에는 GPL·LGPL 구성요소의 소스, 빌드 방법, 모든 구성요소의
목록이 들어 있으며, 안의 `README.md`가 내용과 재빌드·재링크 방법을 설명합니다.

각 구성요소는 해당 라이선스를 따르며, PAVA 사용권과 USB 인증은 그 권리를 제한하지 않습니다.

각 릴리스는 그 버전을 마지막으로 배포한 날부터 최소 3년, 그리고 제품을 지원하는 동안 유지합니다.

요청 및 문의: contact@hirobot.com

## English

Corresponding source for the open-source components in PAVA Studio and PAVA USB
Manager, published by HIROBOT Co., Ltd.

Each version's `PAVA-Open-Source.zip` is attached to the release tagged
`v<version>` on the [Releases](https://github.com/hirobot-kr/pava-studio-third-party-source/releases)
page. The version is shown in PAVA Studio under **Help → About PAVA Studio**.
The archive holds the GPL and LGPL component sources, their build recipes, and
an inventory of every component. Its own `README.md` explains the contents and
how to rebuild or relink each component.

Each component is governed by its own license. The PAVA application license and
USB authorization do not limit those rights.

Each release stays available for at least three years after HIROBOT last
distributes that version, and for as long as HIROBOT supports the product.

Requests and questions: contact@hirobot.com
